# Starship Custom

Tema Omarchy kustom berbasis Starship, dengan nuansa **ungu gelap maskulin** (ekstrem: hampir hitam + aksen indigo kuat).

## Palet

- Background: `#08060e`
- Foreground: `#e0ddf0`
- Accent: `#c4b5fd`
- Ikon: `Yaru-purple`

## Instalasi

```bash
omarchy-theme-install https://github.com/natedekaka/starship-custom.git
# atau
omarchy theme install https://github.com/natedekaka/starship-custom.git
```

Lalu terapkan:

```bash
omarchy theme set "starship-custom"
```
